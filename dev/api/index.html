API Reference

This page provides the complete, categorized reference of types, operators, reconstruction algorithms, and utilities in AstraToolbox.jl.

Each item is documented below with its signatures, parameters, mathematical context, and usage examples.

Backend & Execution Environment

APIs for selecting computational backends (CPU vs. CUDA), querying and configuring GPU devices, and managing native shared libraries.

Backend Selection

Abstract supertype for computational backends in AstraToolbox.jl.

Subtypes include CPUBackend for CPU execution and CUDABackend for GPU-accelerated execution.

Linear Operator Wrapper

AstraToolbox.AstraProjectorMap — Type
AstraProjectorMap(geometry, volume_size; backend=..., options=...)

A matrix-free linear operator representing the CT forward projection matrix $A$. Its adjoint $A'$ represents the backprojection operator $A^T$.

Arguments

  • geometry: 2D or 3D geometry object (e.g., Parallel2DGeometry, Cone3DGeometry).
  • volume_size: Dimensions of the reconstruction volume:
    • For 2D: (nx, ny) or integer n (for (n, n)).
    • For 3D: (nx, ny, nz) or integer n (for (n, n, n)).
  • backend: Computational backend (cpu() or cuda()). Defaults to cpu() for 2D geometries and cuda() for 3D geometries.
  • options: Optional projection options (ProjectionOptions2D or ProjectionOptions3D).

Properties

  • size(A): Returns (prod(sinogram_size), prod(volume_size)).
  • A.volume_size: Dimensions of the reconstruction volume.
  • A.sinogram_size: Dimensions of the projection sinogram array.
  • A.geometry: Underlying projection geometry.
  • A.backend: Computational backend.

Operations

  • A * x: Forward projection of vector x or volume array x.
  • A' * y: Backprojection of sinogram vector y or sinogram array y.
  • mul!(y, A, x): In-place forward projection $y \leftarrow A x$.
  • mul!(x, A', y): In-place backprojection $x \leftarrow A^T y$.
  • 5-argument mul!(y, A, x, α, β): In-place $y \leftarrow \alpha A x + \beta y$.
  • Interoperates directly with LinearAlgebra, IterativeSolvers.jl, and Krylov.jl.

Returns

  • AstraProjectorMap: A matrix-free linear operator implementing AbstractMatrix{Float32}.

Examples

geom = Parallel2DGeometry(range(0, pi, length=180); detector_count=256)
A = AstraProjectorMap(geom, (256, 256))

# Forward projection
vol = shepp_logan(256)
sino = A * vol              # Returns 256x180 Array{Float32, 2}
sino_vec = A * vec(vol)     # Returns 1D Vector{Float32}

# Backprojection
bp = A' * sino              # Returns 256x256 Array{Float32, 2}
bp_vec = A' * sino_vec      # Returns 1D Vector{Float32}

Execute Discrete Algebraic Reconstruction Technique (DART) for 2D or 3D CT reconstruction.

Arguments

  • geometry: 2D or 3D projection geometry.
  • gray_levels: Vector of known discrete attenuation levels.
  • iterations: Number of outer DART iterations (default: 10).

  • volume_size: Dimensions of volume (nx, ny) or (nx, ny, nz).
  • volume_geometry: Optional VolumeGeometry2D / VolumeGeometry3D.
  • window: Optional ROI window coordinates.
  • rng: Random number generator.
  • verbose: Whether to log iteration progress (default: false).

Returns

  • segmentation::Array{Float32}: Final segmented discrete volume.

Apply postalignment to a projection geometry. Can be used to model detector offset or rotation axis offset.

Arguments

  • proj_geom: Input projection geometry (basic or vector-based). If a basic geometry is passed, it is first converted to vector format.
  • factor:
    • For 2D geometries: A single number specifying detector pixel shift.
    • For 3D geometries: A single number (horizontal shift) or a 2-element tuple/vector (factor_u, factor_v) specifying horizontal and vertical pixel shifts.

Returns

  • A modified vector-based projection geometry (ParallelVec2DGeometry, FanFlatVec2DGeometry, ParallelVec3DGeometry, or ConeVec3DGeometry).

Examples

geom = Parallel2DGeometry(range(0, pi, length=180); detector_count=256)
geom_shifted = geom_postalignment(geom, 2.5) # Shift detector by +2.5 pixels

AstraToolbox.add_noise_to_sino! — Function
add_noise_to_sino!(sinogram::Array{Float32}, I0::Real; seed=nothing, rng=nothing)

Adds Poisson noise to a sinogram in-place.

Arguments

  • sinogram: 2D or 3D array of the sinogram.
  • I0: Photon intensity (the higher the intensity, the lower the relative noise).
  • seed: Optional seed for the random number generator.
  • rng: Optional AbstractRNG object.

Returns

  • sinogram: The updated sinogram array with Poisson noise applied (mutated in-place).

Examples

add_noise_to_sino!(sino, 1e5; seed=42)

The logic follows the upstream Python version:

  1. max_val = max(sinogram)
  2. sinogram_scaled = sinogram / max_val
  3. sinogram_ct = I0 * exp(-sinogram_scaled)
  4. sinogram_ct_poisson = rand(Poisson(sinogram_ct))
  5. sinogram_ct_d = sinogram_ct_poisson / I0
  6. sinogram_out = -max_val * log(sinogram_ct_d)
